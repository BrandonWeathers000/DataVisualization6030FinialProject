# DataVisualization6030FinialProject
This project belongs to Brandon Weathers and Mia Yancy. This project is for Federico Iuricich's Data Vislization class at Clemson University 2026.
It uses D3 JS to inform the viewer about cell behavior.

### How to Run
This project currently runs with the python web server.

1. cd into any of the following 
    1. BrandonWork/BoxAndWhisker
    2. BrandonWork/DirectionTracker
    3. MiaWork/cell_anomaly_visualization_split
    4. MiaWork/cell_tracking
2. start the web server with "python3 -m http.sever"
3. visit localhost:8000 in your browser of choice
